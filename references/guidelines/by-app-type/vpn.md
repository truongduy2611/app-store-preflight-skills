# Checklist: VPN & Networking Apps

Guidelines specifically applying to VPN, proxy, and network management apps.

## Critical (Will Reject)

- [ ] **5.4** — Must use the NEVPNManager API
- [ ] **5.4** — Must be from developers enrolled as an organization
- [ ] **5.4** — Must not sell, use, or disclose any data to third parties for any purpose — and the privacy policy must commit to this
- [ ] **5.4** — Clear on-screen declaration of what user data is collected and how it is used, shown **before** any purchase or use of the service
- [ ] **5.4** — If available in a territory that requires a VPN license: license information provided in the App Review Notes field
- [ ] **5.4** — Must not violate local laws where distributed

> Parental control, content blocking, and security apps from approved providers may also use `NEVPNManager` — content blocking alone is not a 5.4 violation.

## Important

- [ ] **5.1.1** — Privacy policy required
- [ ] **2.5.5** — Fully functional on IPv6-only networks
- [ ] **2.3.1(a)** — All app functionality described with specificity in review notes
- [ ] **2.5.19** — No hidden, dormant, or undocumented features
- [ ] **3.1.1** — Premium VPN features must use IAP (not external payment for digital service)
